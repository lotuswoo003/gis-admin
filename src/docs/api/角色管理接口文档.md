# 角色管理接口文档

## 基本信息
- 基础路径: /roles
- 描述: Role Management - 角色增删改查、成员分配和权限管理接口

## 接口列表

### 1. 获取角色详情

**接口地址**: `POST /roles/get/{id}`

**接口描述**: 根据角色ID获取角色详细信息

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 角色ID（路径参数） |

**请求示例**:
```
POST /roles/get/role001
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": "role001",
    "name": "管理员",
    "description": "系统管理员角色",
    "type": "system",
    "orgId": "org001"
  },
  "message": "success"
}
```

### 3. 创建角色

**接口地址**: `POST /roles/create`

**接口描述**: 创建新角色

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |

| name | String | 是 | 角色名称 |
| description | String | 否 | 角色描述 |
| type | String | 否 | 角色类型 |
| orgId | String | 否 | 组织ID |

**请求示例**:

}

### 4. 创建角色并关联权限

**接口地址**: `POST /roles/v1/insert`

**接口描述**: 创建角色的同时关联权限列表

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 是 | 角色名称 |
| description | String | 否 | 角色描述 |
| type | String | 否 | 角色类型 |
| orgId | String | 否 | 组织ID |
| permissionIds | List<String> | 否 | 权限ID列表 |

**请求示例**:
```json
{
  "name": "项目经理",
  "description": "负责项目管理",
  "type": "custom",
  "orgId": "org001",
  "permissionIds": ["perm001", "perm002"]
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": "role002",
  "message": "success"
}
```

### 7. 分页查询角色

**接口地址**: `POST /roles/page`

**接口描述**: 分页查询角色列表，支持按名称筛选

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | Integer | 否 | 页码，默认1 |
| rows | Integer | 否 | 每页数量，默认10 |
| name | String | 否 | 角色名称（模糊查询） |

**请求示例**:
```json
{
  "page": 1,
  "rows": 10,
  "name": "管理"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "total": 50,
    "rows": [
      {
        "id": "role001",
        "name": "系统管理员"
      }
    ]
  },
  "message": "success"
}
```

### 8. 分页查询角色下的用户

**接口地址**: `POST /roles/pageUserById`

**接口描述**: 分页查询指定角色下的用户列表

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| roleId | String | 是 | 角色ID |
| page | Integer | 否 | 页码，默认1 |
| rows | Integer | 否 | 每页数量，默认10 |
| name | String | 否 | 用户名称（模糊查询） |
| phoneNumber | String | 否 | 手机号（模糊查询） |

**请求示例**:
```json
{
  "roleId": "role001",
  "page": 1,
  "rows": 10,
  "name": "张"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "total": 20,
    "rows": [
      {
        "id": "user001",
        "name": "张三",
        "phoneNumber": "13800138000"
      }
    ]
  },
  "message": "success"
}
```
