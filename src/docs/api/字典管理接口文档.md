# 字典管理接口文档

## 基本信息
- 基础路径: /dict
- 描述: 数据字典管理接口

## 接口列表

### 1. 获取字典详情

**接口地址**: `GET /dict/{id}`

**接口描述**: 根据字典类型ID获取字典详情及其数据项

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 字典类型ID（路径参数） |

**请求示例**:
```
GET /dict/dict001
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": "dict001",
    "name": "性别",
    "code": "gender",
    "dataList": [
      {
        "id": "data001",
        "label": "男",
        "value": "male",
        "typeId": "dict001"
      },
      {
        "id": "data002",
        "label": "女",
        "value": "female",
        "typeId": "dict001"
      }
    ]
  },
  "message": "success"
}
```

---

### 2. 字典类型列表

**接口地址**: `GET /dict`

**接口描述**: 获取所有字典类型及其数据项

**请求参数**: 无

**请求示例**:
```
GET /dict
```

**响应示例**:
```json
{
  "code": 200,
  "data": [
    {
      "id": "dict001",
      "name": "性别",
      "code": "gender",
      "dataList": [
        {
          "id": "data001",
          "label": "男",
          "value": "male"
        }
      ]
    }
  ],
  "message": "success"
}
```

---

### 3. 创建字典

**接口地址**: `POST /dict`

**接口描述**: 创建字典类型及其数据项

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 是 | 字典类型名称 |
| code | String | 是 | 字典类型编码 |
| dataList | List | 否 | 数据项列表 |
| dataList[].label | String | 是 | 数据项标签 |
| dataList[].value | String | 是 | 数据项值 |
| dataList[].sort | Integer | 否 | 排序 |

**请求示例**:
```json
{
  "name": "学历",
  "code": "education",
  "dataList": [
    {
      "label": "本科",
      "value": "bachelor",
      "sort": 1
    },
    {
      "label": "硕士",
      "value": "master",
      "sort": 2
    }
  ]
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": "dict002",
  "message": "success"
}
```

---

### 4. 更新字典

**接口地址**: `PUT /dict/{id}`

**接口描述**: 更新字典类型及其数据项（会先删除旧数据项，再添加新数据项）

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 字典类型ID（路径参数） |
| name | String | 否 | 字典类型名称 |
| code | String | 否 | 字典类型编码 |
| dataList | List | 否 | 数据项列表 |

**请求示例**:
```json
{
  "name": "学历层次",
  "code": "education",
  "dataList": [
    {
      "label": "专科",
      "value": "associate",
      "sort": 1
    },
    {
      "label": "本科",
      "value": "bachelor",
      "sort": 2
    },
    {
      "label": "硕士",
      "value": "master",
      "sort": 3
    }
  ]
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```

---

### 5. 删除字典

**接口地址**: `DELETE /dict/{id}`

**接口描述**: 删除字典类型及其所有数据项

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 字典类型ID（路径参数） |

**请求示例**:
```
DELETE /dict/dict002
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```
