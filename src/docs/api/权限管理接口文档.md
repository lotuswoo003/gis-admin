# 权限管理接口文档

## 基本信息
- 基础路径: /permission
- 描述: 权限管理接口

## 接口列表

### 1. 获取权限详情

**接口地址**: `POST /permission/get/{id}`

**接口描述**: 根据权限ID获取权限详细信息

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 权限ID（路径参数） |

**请求示例**:
```
POST /permission/get/perm001
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": "perm001",
    "name": "用户管理",
    "code": "user:manage",
    "type": "menu",
    "parentId": null,
    "treePath": "/perm001"
  },
  "message": "success"
}
```

### 2. 权限列表

**接口地址**: `POST /permission/list`

**接口描述**: 获取所有权限列表

**请求参数**: 无

**请求示例**:
```
POST /permission/list
```

**响应示例**:
```json
{
  "code": 200,
  "data": [
    {
      "id": "perm001",
      "name": "用户管理",
      "code": "user:manage",
      "type": "menu"
    }
  ],
  "message": "success"
}
```

---

### 3. 分页查询权限

**接口地址**: `POST /permission/page`

**接口描述**: 分页查询权限列表

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | Integer | 否 | 页码，默认1 |
| rows | Integer | 否 | 每页数量，默认10 |
| name | String | 否 | 权限名称（模糊查询） |

**请求示例**:
```json
{
  "page": 1,
  "rows": 10,
  "name": "用户"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "total": 50,
    "rows": [
      {
        "id": "perm001",
        "name": "用户管理"
      }
    ]
  },
  "message": "success"
}
```

---

### 4. 创建权限

**接口地址**: `POST /permission/create`

**接口描述**: 创建新权限

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 是 | 权限名称 |
| code | String | 是 | 权限编码 |
| type | String | 是 | 权限类型（menu/button） |
| parentId | String | 否 | 父权限ID |
| icon | String | 否 | 图标 |
| path | String | 否 | 路径 |

**请求示例**:
```json
{
  "name": "新增用户",
  "code": "user:add",
  "type": "button",
  "parentId": "perm001"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": "perm002",
  "message": "success"
}
```

### 7. 查询子权限

**接口地址**: `POST /permission/children`

**接口描述**: 根据父ID和类型查询子权限

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| parentId | String | 是 | 父权限ID |
| type | String | 否 | 权限类型 |

**请求示例**:
```json
{
  "parentId": "perm001",
  "type": "button"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": [
    {
      "id": "perm002",
      "name": "新增用户",
      "parentId": "perm001"
    }
  ],
  "message": "success"
}
```

### 8. 根据树路径查询权限

**接口地址**: `POST /permission/treePath`

**接口描述**: 根据树路径查询相关权限

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| treePath | String | 是 | 树路径 |

**请求示例**:
```json
{
  "treePath": "/perm001"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": [
    {
      "id": "perm001",
      "name": "用户管理",
      "treePath": "/perm001"
    },
    {
      "id": "perm002",
      "name": "新增用户",
      "treePath": "/perm001/perm002"
    }
  ],
  "message": "success"
}
```

### 10. 根据组织获取权限树

**接口地址**: `GET /permission/treeByOrg`

**接口描述**: 获取当前组织的管理员权限树

**请求参数**: 无（从登录上下文获取组织ID）

**请求示例**:
```
GET /permission/treeByOrg
```

**响应示例**:
```json
{
  "code": 200,
  "data": [
    {
      "id": "perm001",
      "name": "用户管理",
      "children": []
    }
  ],
  "message": "success"
}
```
