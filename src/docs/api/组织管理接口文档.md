# 组织管理接口文档

## 基本信息
- 基础路径: /organization
- 描述: 组织管理接口

## 接口列表

### 1. 获取组织详情

**接口地址**: `GET /organization/get/{id}`

**接口描述**: 根据组织ID获取组织详细信息

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 组织ID（路径参数） |

**请求示例**:
```
GET /organization/get/org001
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": "org001",
    "name": "某某公司",
    "type": "company",
    "address": "北京市朝阳区"
  },
  "message": "success"
}
```

---

### 2. 保存组织

**接口地址**: `POST /organization/save`

**接口描述**: 创建新组织

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 是 | 组织名称 |
| type | String | 否 | 组织类型 |
| parentId | String | 否 | 父组织ID |
| address | String | 否 | 地址 |

**请求示例**:
```json
{
  "name": "某某分公司",
  "type": "branch",
  "parentId": "org001",
  "address": "上海市浦东新区"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": "org002",
  "message": "success"
}
```

---

### 3. 更新组织

**接口地址**: `POST /organization/update`

**接口描述**: 更新组织信息

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 组织ID |
| name | String | 否 | 组织名称 |
| type | String | 否 | 组织类型 |
| address | String | 否 | 地址 |

**请求示例**:
```json
{
  "id": "org002",
  "name": "某某分公司（华东）",
  "address": "上海市浦东新区张江"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```

---

### 4. 删除组织

**接口地址**: `POST /organization/delete`

**接口描述**: 删除指定组织

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 组织ID（查询参数） |

**请求示例**:
```
POST /organization/delete?id=org002
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```

---

### 5. 分页查询组织

**接口地址**: `POST /organization/page`

**接口描述**: 分页查询组织列表

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | Integer | 否 | 页码，默认1 |
| rows | Integer | 否 | 每页数量，默认10 |
| name | String | 否 | 组织名称（模糊查询） |

**请求示例**:
```json
{
  "page": 1,
  "rows": 10,
  "name": "分公司"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "total": 30,
    "rows": [
      {
        "id": "org002",
        "name": "某某分公司"
      }
    ]
  },
  "message": "success"
}
```

---

### 6. 绑定目标组织

**接口地址**: `POST /organization/bindTargets`

**接口描述**: 绑定源组织与多个目标组织的关系

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| sourceOrgId | String | 是 | 源组织ID |
| targetOrgIds | List<String> | 是 | 目标组织ID列表 |

**请求示例**:
```json
{
  "sourceOrgId": "org001",
  "targetOrgIds": ["org002", "org003", "org004"]
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```

---

### 7. 查询目标组织列表

**接口地址**: `GET /organization/targetOrgs`

**接口描述**: 查询源组织关联的所有目标组织

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| sourceOrgId | String | 是 | 源组织ID（查询参数） |

**请求示例**:
```
GET /organization/targetOrgs?sourceOrgId=org001
```

**响应示例**:
```json
{
  "code": 200,
  "data": [
    {
      "id": "org002",
      "name": "目标组织A"
    },
    {
      "id": "org003",
      "name": "目标组织B"
    }
  ],
  "message": "success"
}
```
