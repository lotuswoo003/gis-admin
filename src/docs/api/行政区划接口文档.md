# 行政区划接口文档

## 基本信息
- 基础路径: /postal-code
- 描述: 行政区划（邮政编码）查询接口

## 接口列表

### 1. 查询行政区划列表

**接口地址**: `POST /postal-code/list`

**接口描述**: 根据父ID和级别查询行政区划列表

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| parentId | String | 否 | 父级ID，为空时查询顶级（省级） |
| level | Integer | 否 | 行政级别（1-省，2-市，3-区/县） |

**请求示例**:
```json
{
  "parentId": "110000",
  "level": 2
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": [
    {
      "id": "110100",
      "name": "北京市",
      "code": "110100",
      "parentId": "110000",
      "level": 2
    },
    {
      "id": "110200",
      "name": "县",
      "code": "110200",
      "parentId": "110000",
      "level": 2
    }
  ],
  "message": "success"
}
```
