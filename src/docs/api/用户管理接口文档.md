# 用户管理接口文档

## 基本信息
- 基础路径: /user
- 描述: 用户表 CRUD 接口

## 接口列表

### 1. 获取用户详情

**接口地址**: `POST /user/get/{id}`

**接口描述**: 根据用户ID获取用户详细信息

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 用户ID（路径参数） |

**请求示例**:
```
POST /user/get/123456
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": "123456",
    "username": "zhangsan",
    "name": "张三",
    "phoneNumber": "13800138000",
    "email": "zhangsan@example.com"
  },
  "message": "success"
}
```

### 4. 分页查询当前组织用户

**接口地址**: `POST /user/page`

**接口描述**: 根据当前登录组织过滤后分页返回用户列表

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | Integer | 否 | 页码，默认1 |
| rows | Integer | 否 | 每页数量，默认10 |
| name | String | 否 | 用户名称（模糊查询） |
| phoneNumber | String | 否 | 手机号（模糊查询） |

**请求示例**:
```json
{
  "page": 1,
  "rows": 10,
  "name": "张"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "total": 100,
    "rows": [
      {
        "id": "123456",
        "username": "zhangsan",
        "name": "张三"
      }
    ]
  },
  "message": "success"
}
```

### 5. 创建用户

**接口地址**: `POST /user/create`

**接口描述**: 创建新用户，可同时关联部门和组织

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| user | Object | 是 | 用户信息对象 |
| user.username | String | 是 | 用户名 |
| user.name | String | 是 | 姓名 |
| user.phoneNumber | String | 是 | 手机号 |
| user.password | String | 是 | 密码 |
| deptIds | List<String> | 否 | 部门ID列表 |
| orgIds | List<String> | 否 | 组织ID列表 |

**请求示例**:
```json
{
  "user": {
    "username": "zhangsan",
    "name": "张三",
    "phoneNumber": "13800138000",
    "password": "123456"
  },
  "deptIds": ["dept001"],
  "orgIds": ["org001"]
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": "123456",
  "message": "success"
}
```

### 9. 用户切换组织

**接口地址**: `POST /user/changeOrganization`

**接口描述**: 当前用户切换到另一个组织，返回新的Token

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | String | 是 | 当前Token（请求头） |
| organizationId | String | 是 | 目标组织ID |

**请求示例**:
```json
{
  "organizationId": "org002"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "accessToken": "new_token_value",
    "expiresIn": 7200,
    "userId": "123456",
    "organizationId": "org002"
  },
  "message": "success"
}
```

### 11. 查询当前用户可视边界

**接口地址**: `POST /user/v1/select-boundary`

**接口描述**: 查询当前用户可视的地理边界范围（特殊功能接口）

**请求参数**: 无

**请求示例**:
```
POST /user/v1/select-boundary
```

**响应示例**:
```json
{
  "code": 200,
  "data": "POLYGON((116.3 39.9, 116.4 39.9, 116.4 40.0, 116.3 40.0, 116.3 39.9))",
  "message": "success"
}
```
