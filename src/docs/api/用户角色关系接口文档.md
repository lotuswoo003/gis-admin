# 用户角色关系接口文档

## 基本信息
- 基础路径: /user-roles
- 描述: User Role - 用户与角色关联管理

## 接口列表

### 1. 查询角色下的用户列表

**接口地址**: `GET /user-roles/{roleId}/users`

**接口描述**: 获取指定角色关联的所有用户

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| roleId | String | 是 | 角色ID（路径参数） |

**请求示例**:
```
GET /user-roles/role001/users
```

**响应示例**:
```json
{
  "code": 200,
  "data": [
    {
      "id": "user001",
      "username": "zhangsan",
      "name": "张三"
    },
    {
      "id": "user002",
      "username": "lisi",
      "name": "李四"
    }
  ],
  "message": "success"
}
```

---

### 2. 更新角色用户

**接口地址**: `POST /user-roles/users`

**接口描述**: 批量更新角色的用户关联（同步角色成员）

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| roleId | String | 是 | 角色ID |
| userIds | List<String> | 是 | 用户ID列表 |

**请求示例**:
```json
{
  "roleId": "role001",
  "userIds": ["user001", "user002", "user003"]
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```
