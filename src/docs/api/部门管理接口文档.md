# 部门管理接口文档

## 基本信息
- 基础路径: /department
- 描述: Department - 部门管理接口

## 接口列表

### 1. 获取部门详情

**接口地址**: `GET /department/{id}`

**接口描述**: 根据部门ID获取部门详细信息

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 部门ID（路径参数） |

**请求示例**:
```
GET /department/dept001
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": "dept001",
    "name": "技术部",
    "parentId": null,
    "organizationId": "org001"
  },
  "message": "success"
}
```

---

### 2. 查询部门树

**接口地址**: `POST /department/v1/select-tree`

**接口描述**: 查询当前组织下的部门树结构

**请求参数**: 无（从登录上下文获取当前组织ID）

**请求示例**:
```
POST /department/v1/select-tree
```

**响应示例**:
```json
{
  "code": 200,
  "data": [
    {
      "id": "dept001",
      "name": "技术部",
      "children": [
        {
          "id": "dept002",
          "name": "研发组"
        }
      ]
    }
  ],
  "message": "success"
}
```

---

### 3. 创建部门

**接口地址**: `POST /department/v1/insert`

**接口描述**: 创建新部门

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 是 | 部门名称 |
| parentId | String | 否 | 父部门ID |
| organizationId | String | 是 | 组织ID |

**请求示例**:
```json
{
  "name": "测试部",
  "parentId": "dept001",
  "organizationId": "org001"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": "dept003",
  "message": "success"
}
```

---

### 4. 更新部门

**接口地址**: `POST /department/v1/update`

**接口描述**: 更新部门信息

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 部门ID |
| name | String | 否 | 部门名称 |
| parentId | String | 否 | 父部门ID |

**请求示例**:
```json
{
  "id": "dept003",
  "name": "质量保障部",
  "parentId": "dept001"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```

---

### 5. 删除部门

**接口地址**: `POST /department/v1/delete`

**接口描述**: 删除指定部门

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 部门ID |

**请求示例**:
```json
"dept003"
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```

---

### 6. 批量更新用户部门关系

**接口地址**: `POST /department/v1/updateUserDepartment`

**接口描述**: 批量更新用户与部门的关联关系

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| requests | List | 是 | 用户部门更新请求列表 |
| requests[].userId | String | 是 | 用户ID |
| requests[].departmentIds | List<String> | 是 | 部门ID列表 |

**请求示例**:
```json
[
  {
    "userId": "user001",
    "departmentIds": ["dept001", "dept002"]
  },
  {
    "userId": "user002",
    "departmentIds": ["dept003"]
  }
]
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```
