# 登录接口文档

## 基本信息
- 基础路径: /login
- 描述: 用户登录和登出接口

## 接口列表

### 1. 账号/手机号+密码登录

**接口地址**: `POST /login/password`

**接口描述**: 使用账号或手机号配合密码进行登录

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| account | String | 是 | 账号或手机号 |
| password | String | 是 | 密码 |

**请求示例**:
```json
{
  "account": "zhangsan",
  "password": "123456"
}
```

**响应示例**:
```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresIn": 7200,
  "userId": "123456",
  "organizationId": "org001"
}
```

---

### 2. 手机号验证码登录

**接口地址**: `POST /login/phone-verify-code`

**接口描述**: 使用手机号和验证码进行登录

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| phoneNumber | String | 是 | 手机号 |
| verifyCode | String | 是 | 验证码 |

**请求示例**:
```json
{
  "phoneNumber": "13800138000",
  "verifyCode": "123456"
}
```

**响应示例**:
```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresIn": 7200,
  "userId": "123456",
  "organizationId": "org001"
}
```

---

### 3. 退出登录

**接口地址**: `POST /login/logout`

**接口描述**: 退出当前登录状态，清除Token

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | String | 是 | 用户Token（请求头） |

**请求示例**:
```
POST /login/logout
Headers:
  Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**响应示例**:
```
无返回内容（HTTP 200）
```
