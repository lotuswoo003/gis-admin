# 权限包管理接口文档

## 基本信息
- 基础路径: /permissionPackage
- 描述: Permission Package - CRUD and binding APIs for permission packages

## 接口列表

### 1. 获取权限包详情

**接口地址**: `POST /permissionPackage/get/{id}`

**接口描述**: 根据权限包ID获取详细信息

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 权限包ID（路径参数） |

**请求示例**:
```
POST /permissionPackage/get/pkg001
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": "pkg001",
    "name": "基础权限包",
    "description": "包含基础功能权限"
  },
  "message": "success"
}
```

### 6. 更新权限包

**接口地址**: `POST /permissionPackage/update`

**接口描述**: 更新权限包信息

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 权限包ID |
| name | String | 否 | 权限包名称 |
| description | String | 否 | 权限包描述 |

**请求示例**:
```json
{
  "id": "pkg002",
  "name": "企业高级权限包",
  "description": "包含企业高级功能权限"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```

**前端实现说明**:
- 权限包管理页编辑权限时，只展示启用状态的权限（`disableFlag = 0`）。
- 已禁用权限不会在编辑树中显示，也不会被前端再次勾选或提交。

### 8. 绑定权限包到组织

**接口地址**: `POST /permissionPackage/bind/org`

**接口描述**: 将多个权限包绑定到指定组织

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| organizationId | String | 是 | 组织ID |
| packageIds | List<String> | 是 | 权限包ID列表 |

**请求示例**:
```json
{
  "organizationId": "org001",
  "packageIds": ["pkg001", "pkg002"]
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```

### 10. 绑定权限到权限包

**接口地址**: `POST /permissionPackage/bind/permissions`

**接口描述**: 将多个权限绑定到指定权限包

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| packageId | String | 是 | 权限包ID |
| permissionIds | List<String> | 是 | 权限ID列表 |

**请求示例**:
```json
{
  "packageId": "pkg001",
  "permissionIds": ["perm001", "perm002", "perm003"]
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```
