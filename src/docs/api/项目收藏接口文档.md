# 项目收藏接口文档

## 基本信息
- 基础路径: `/projectCollect`
- 描述: 项目收藏管理接口，支持用户收藏项目
- Controller: ProjectCollectController

## 接口列表

### 1. 获取收藏详情

**接口地址**: `POST /projectCollect/get/{id}`

**接口描述**: 根据ID获取收藏详情

**路径参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 收藏ID |

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": "123456",
    "userId": "user001",
    "projectId": "proj001",
    "organizationId": "org001",
    "type": 1,
    "createdAt": "2024-01-01T00:00:00Z",
    "updatedAt": "2024-01-01T00:00:00Z"
  },
  "message": "success"
}
```

### 3. 创建收藏

**接口地址**: `POST /projectCollect/create`

**接口描述**: 新增一条收藏记录（用户收藏项目）

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | String | 是 | 用户ID |
| projectId | String | 否 | 项目ID |
| organizationId | String | 是 | 组织ID |
| type | Integer | 否 | 收藏类型（1-项目收藏 2-售前收藏） |

**请求示例**:
```json
{
  "userId": "user001",
  "projectId": "proj001",
  "organizationId": "org001",
  "type": 1
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": "123456",
  "message": "success"
}
```

| projectId | String | 否 | 项目ID |
| organizationId | String | 否 | 组织ID |

**请求示例**:
```json

  "id": "123456",
  "type": 2

```

**响应示例**:
```json

  "data": true,
  "message": "success"
```

**请求参数**:

## 业务逻辑说明

### 收藏类型
- **type = 1**: 项目收藏，用户收藏正式项目
- **type = 2**: 售前收藏，用户收藏售前项目

### 收藏功能
- 用户可以收藏多个项目
- 同一个项目可以被多个用户收藏
- 收藏记录关联用户、项目和组织
- 支持按收藏时间倒序排列

## 注意事项

1. **用户ID必填**：每条收藏记录必须关联一个用户
2. **组织ID必填**：每条收藏记录必须关联一个组织
3. **项目ID可选**：售前收藏可能没有项目ID
4. **逻辑删除**：删除操作为逻辑删除，不会物理删除数据
5. **排序规则**：查询结果按创建时间倒序排列（最新收藏在前）
6. **唯一性**：建议在业务层避免用户重复收藏同一项目
