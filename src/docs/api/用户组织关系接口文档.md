# 用户组织关系接口文档

## 基本信息
- 基础路径: /user_organization
- 描述: 用户与组织关系管理接口

## 接口列表

### 1. 查询用户组织列表

**接口地址**: `POST /user_organization/v1/select-list`

**接口描述**: 查询用户的组织关联列表

**请求参数**: 无

**请求示例**:
```
POST /user_organization/v1/select-list
```

**响应示例**:
```json
{
  "code": 200,
  "data": [
    {
      "userId": "user001",
      "organizationId": "org001",
      "userName": "张三",
      "organizationName": "某某公司"
    }
  ],
  "message": "success"
}
```

---

### 2. 保存用户组织关系

**接口地址**: `POST /user_organization/save`

**接口描述**: 创建用户与组织的关联关系

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | String | 是 | 用户ID |
| organizationId | String | 是 | 组织ID |

**请求示例**:
```json
{
  "userId": "user001",
  "organizationId": "org002"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": "uo001",
  "message": "success"
}
```

---

### 3. 更新用户组织关系

**接口地址**: `POST /user_organization/update`

**接口描述**: 更新用户与组织的关联关系

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 关系ID |
| userId | String | 否 | 用户ID |
| organizationId | String | 否 | 组织ID |

**请求示例**:
```json
{
  "id": "uo001",
  "organizationId": "org003"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```

---

### 4. 删除用户组织关系

**接口地址**: `POST /user_organization/delete`

**接口描述**: 删除用户与组织的关联关系

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 关系ID（查询参数） |

**请求示例**:
```
POST /user_organization/delete?id=uo001
```

**响应示例**:
```json
{
  "code": 200,
  "data": true,
  "message": "success"
}
```
