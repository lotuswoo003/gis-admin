# 附件管理接口文档

## 基本信息
- 基础路径: /attach
- 描述: Attachment Web API - 附件上传接口

## 接口列表

### 1. 上传文件

**接口地址**: `POST /attach/upload`

**接口描述**: 上传文件并返回附件ID

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | File | 是 | 要上传的文件（multipart/form-data） |

**请求示例**:
```
POST /attach/upload
Content-Type: multipart/form-data

file: [binary file data]
```

**响应示例**:
```json
{
  "code": 200,
  "data": "attach123456",
  "message": "success"
}
```

---

### 2. 更新附件信息

**接口地址**: `POST /attach/upload-select`

**接口描述**: 上传附件并获取上传附件的信息

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| attachId | String | 是 | 附件ID |
| fileName | String | 否 | 文件名 |
| fileSize | Long | 否 | 文件大小 |

**请求示例**:
```json
{
  "attachId": "attach123456",
  "fileName": "document.pdf",
  "fileSize": 1024000
}
```

**响应示例**:
```json
{
  "id": "attach123456",
  "name": "document.pdf",
  "size": 1024000,
  "url": "https://example.com/files/document.pdf"
}
```
