# 工序单价接口文档

## 基本信息
- 基础路径: `/processUnitPrice`
- 描述: 智能工艺人机材单价管理接口
- Controller: ProcessUnitPriceController

## 接口列表

### 1. 获取单价详情

**接口地址**: `POST /processUnitPrice/get/{id}`

**接口描述**: 根据ID获取工序单价详情

**路径参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 单价ID |

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": "123456",
    "province": "江苏省",
    "city": "南京市",
    "provinceId": "320000",
    "cityId": "320100",
    "type": "1",
    "name": "草坪修剪",
    "unit": "平方米",
    "organizationId": "org001",
    "organizationName": "某某园林公司",
    "price": 10.50,
    "createdAt": "2024-01-01T00:00:00Z",
    "updatedAt": "2024-01-01T00:00:00Z"
  },
  "message": "success"
}
```

## 数据库索引

为了优化按 `organization_id` 的查询性能，已在数据库中创建索引：

```sql
CREATE INDEX idx_process_unit_price_org ON process_unit_price (organization_id);
CREATE INDEX idx_process_unit_price_type ON process_unit_price (type);
```

## 注意事项

1. **organization_id字段**：此字段用于关联组织，支持按组织过滤单价数据
2. **organizationName字段**：此字段为联表查询结果，仅在查询时返回，创建和更新时不需要传递
3. **逻辑删除**：删除操作为逻辑删除，不会物理删除数据
4. **分页查询**：建议使用分页查询以提高性能
5. **模糊查询**：仅 `name` 字段支持模糊查询，其他字段均为精确匹配
